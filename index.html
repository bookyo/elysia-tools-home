05 · Built to be automated

A tool backend, not just a UI.

Every tool has an HTTP API with cURL, JavaScript, and Python examples. Anonymous requests work within the rate limit; API keys can be scoped to all tools or a specific list.

curl -X POST 'https://api.elysiatools.com/en/api/tools/hash-generator' \
  -H 'Content-Type: application/json' \
  -d '{"algorithm":"sha256","inputText":"Elysia Tools","inputFormat":"text","outputFormat":"hex"}'

{"data":{"result":"SHA256 Hash:\n4a5d6d66…"},"type":"text"}

Discovery endpoints

List tools, categories, and search results; POST executes a tool.

Scoped API keys

Create keys in the dashboard, limit them to specific tools, enable, disable, reset, or delete them.

Ask Elysia

Describe a task in natural language; the chat agent finds the tool, loads its form, and keeps the result in the conversation. Commands: \tool, \sample, \tag, \run.

A node canvas for chaining tools into repeatable workflows. Running a workflow requires sign-in.

Questions, answered.

What is Elysia Tools?

A free online tool collection covering files, data, text, images, audio, video, PDFs, developer formats, and AI tasks. It currently holds 3,201 tools across 24 categories, 593 sample collections, 465 interactive visualizations, 103 in-browser file viewers, and 233 topic hubs. Nothing needs to be installed.

Is it free?

The free plan is available now and normal use does not require an account. Free limits: 100 MB uploads, standard tools at 10 per minute and 100 per day, AI tools at 20 per day, 10-minute audio, 5-minute video, and 10 media tasks per day. Plus and Pro are shown as planned tiers and are not open yet.

Do I need an account?

No. Optional sign-in uses an email magic link, Google, or GitHub. Accounts are mainly for the dashboard, API keys, and running Workflow Workbench workflows.

What happens to uploaded files?

Files are processed temporarily in memory or on disk and deleted within six hours. The site says it does not retain, view, or share file contents. Run history records only the tool, time, status, and duration.

Does everything run in my browser?

No. The interface is in the browser, but most tools run server-side. The 103 viewers are explicitly local and do not upload the file. A few specific tools, such as the private offline period tracker, are also designed to run locally. Check the individual tool page.

Is there an API?

Yes. Every tool has HTTP API documentation with cURL, JavaScript, and Python examples. Discovery endpoints list tools, categories, and search results; POST executes a tool. API keys can be created in the dashboard and scoped to all tools or a specific list. Free limits apply.

Is there MCP support?

There is MCP integration documentation: a per-tool SSE address, tools/list, tools/call, and chaining up to 20 tool IDs. As of November 9, 2026, the public SSE endpoint returned 404, so confirm availability with the operator before relying on it.

Can I preview documents without downloading them?

Yes. 103 viewers cover Word, PowerPoint, Excel, PDF, text, images, audio, video, archives, CAD, 3D, and drawing formats. They render in the browser without uploading or server-side processing.
